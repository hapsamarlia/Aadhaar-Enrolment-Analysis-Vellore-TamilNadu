# Monthly Aadhaar Enrolment Analysis – Vellore District

This repository contains a monthly-wise analysis of Aadhaar enrolment data for Vellore district, Tamil Nadu, using official UIDAI open data.

## Repository Structure
- PowerBI: Power BI dashboard (.pbix)
- Notebook: Google Colab notebook (.ipynb)
- Data: Aadhaar enrolment dataset (CSV)

## Tools Used
- Power BI
- Power Query
- Python (Google Colab)

## Note
The Power BI file can be downloaded and opened using Power BI Desktop.
